# note-cli

This extension adds skills for note.com, built on the bundled `note-cli` (`dist/note-cli.js` in this extension's directory, run with [Bun](https://bun.sh)). Load the matching skill before acting:

- `skills/draft/SKILL.md`: save, update and read back Markdown drafts on note.com (never publishes)
- `skills/research/SKILL.md`: search and analyze note.com articles, hashtags and creators
- `skills/my-stats/SKILL.md`: review the logged-in user's page views, likes and comments
